## Overview

The **X11** display/input [driver](https://github.com/lvgl/lvgl/tree/master/src/drivers/x11) opens a window
on an X11 desktop through Xlib and reads mouse, mousewheel and keyboard input.

Its main purpose is development: testing and debugging an LVGL application in a window on a Linux machine,
without dedicated hardware. It is an alternative to the [Wayland](/integration/embedded_linux/drivers/wayland),
[SDL](/integration/pc/sdl) and [GLFW](/integration/embedded_linux/drivers/glfw) drivers.

X11 is a CPU-blit driver with no GPU path. For production embedded targets prefer
[DRM](/integration/embedded_linux/drivers/drm) or [Wayland](/integration/embedded_linux/drivers/wayland).

## Configuration

Enable <ApiLink name="LV_USE_X11" />.

Enabling it is also what pulls Xlib into the build — LVGL's CMake integration resolves it for you, so there
is nothing to link by hand. Xlib cannot be built from source by LVGL, so it must already be present on the
system or in your sysroot. See [Dependency Management](/integration/building/cmake).

<ApiLink name="LV_COLOR_DEPTH" /> must be `16`, `24` or `32`. A depth of `8` compiles but renders black.

### Options

| Symbol | Default | Effect |
|---|---|---|
| `LV_X11_RENDER_MODE` | `LV_DISPLAY_RENDER_MODE_PARTIAL` | Render mode. Partial is recommended; see below. |
| `LV_X11_DOUBLE_BUFFER` | on | Use two buffers. Recommended. |
| `LV_X11_DIRECT_EXIT` | on | Exit the application once all windows are closed. Turn it off to handle closure yourself. |

`LV_X11_RENDER_MODE` accepts <ApiLink name="LV_DISPLAY_RENDER_MODE_PARTIAL" />,
<ApiLink name="LV_DISPLAY_RENDER_MODE_DIRECT" /> or <ApiLink name="LV_DISPLAY_RENDER_MODE_FULL" />. Partial
is the default and the right choice here: the driver hands finished pixels to the X server one region at a
time, so the full-screen modes buy nothing and cost memory.

## Usage

Create the window with <ApiLink name="lv_x11_window_create" />, then attach input with
<ApiLink name="lv_x11_inputs_create" />. The second argument is an optional cursor image; pass `NULL` for
none.

```c
int main(int argc, char ** argv)
{
    lv_init();
    /* Don't forget the tick callback */

    lv_display_t * disp = lv_x11_window_create("LVGL X11 Simulation", 800, 480);

    /* Keyboard, mouse and mousewheel */
    lv_x11_inputs_create(disp, NULL);

    lv_demo_widgets();

    while(1) {
        uint32_t time_until_next = lv_timer_handler();
        if(time_until_next == LV_NO_TIMER_READY) time_until_next = LV_DEF_REFR_PERIOD;
        lv_delay_ms(time_until_next);
    }
}
```

Call <ApiLink name="lv_x11_window_create" /> again to open more windows; each returns its own display.

### Handling window closure yourself

With `LV_X11_DIRECT_EXIT` off, the application decides what happens when a window closes. Register an
<ApiLink name="LV_EVENT_DELETE" /> handler on the display and run your own loop condition:

```c
static bool terminated = false;

static void on_close_cb(lv_event_t * e)
{
    LV_UNUSED(e);
    terminated = true;
}

int main(int argc, char ** argv)
{
    lv_init();

    lv_display_t * disp = lv_x11_window_create("LVGL X11 Simulation", 800, 480);
    lv_display_add_event_cb(disp, on_close_cb, LV_EVENT_DELETE, disp);

    /* Attach inputs, optionally with a cursor image */
    LV_IMAGE_DECLARE(mouse_cursor_icon);
    lv_x11_inputs_create(disp, &mouse_cursor_icon);

    while(!terminated) {
        uint32_t time_until_next = lv_timer_handler();
        if(time_until_next == LV_NO_TIMER_READY) time_until_next = LV_DEF_REFR_PERIOD;
        lv_delay_ms(time_until_next);
    }

    /* Clean up here */
}
```

## Support

| Capability | Value |
|---|---|
| Rotation | None |
| Runtime resolution change | Yes — the driver follows window resizes |
| Runtime color format change | No |
| Color formats | Derived from <ApiLink name="LV_COLOR_DEPTH" /> (`16`, `24` or `32`) |
| Multiple displays / windows | Yes — one display per window |
| Hardware acceleration | None |
| Render mode | Partial (default) — configurable via `LV_X11_RENDER_MODE` |
| Input | Built in — mouse, mousewheel and keyboard via <ApiLink name="lv_x11_inputs_create" /> |

Rotation is not implemented in this driver. If you need a rotated display on a desktop, rotate at the window
manager level or use a driver that supports it.
